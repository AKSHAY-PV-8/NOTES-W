=>>> Both docker and Virtual machines are virtualizing tools 

? what is Virtual machines ?

->"A Virtual Machine is a software-based computer that runs inside a 
real physical computer. It behaves exactly like a real computer 
with its own OS, CPU, RAM, and storage — but it is completely virtual. 
Multiple VMs can run on one physical machine at the same time."

? what is Virtualization ? 

-> "Virtualization is the process of creating a virtual (fake) version
 of a physical resource like a computer, server, storage, or network 
 using software. Instead of using one physical machine for one job, 
 virtualization allows one physical machine to act as many machines 
 simultaneously."



? what is the difference between docker and virtual machine both do virtualize ?

docker :- Contains the OS application layer 
        - Services and apps installed om top that layer (example: java runtime, python runtime)
        - it uses kernel of the host it don't have it's own kernel 

VM :- it has application layer and it's own kernel 
    - it virtualize complete OS system 


differences: 
    - docker image is much smaller (save lots of disk place)
    - docker can fun much faster than VM (reuses the host kernel, vm put up th kernel every time it start)
    - problem -> compability: 
                    - vm is compatible with all OS 
                    - docker compatible only with which is used

DOCKER IMAGES vs DOCKER CONTAINERS 

? what is docker image ?

-> A Docker Image is a ready-made package that contains everything 
needed to run an application
-> includes app source code, but also complete environment configuration 

? what is docker container ?

-> running instance of docker image 
-> A Docker Container is a lightweight, isolated, and runnable 
instance of a Docker Image. It contains the application and everything
 it needs to run. Containers share the host OS kernel, making them
  faster and lighter than Virtual Machines. Multiple containers can 
  run on the same machine independently without affecting each other.
